东方龙童
IP设计

一个融合东方龙文化、潮玩手办与儿童情绪表达的原创IP形象。

PROJECT CONCEPT

本项目以中国龙文化为灵感来源，结合潮玩角色设计语言，塑造出一个具有亲和力、 传播性与文创延展价值的原创IP形象。角色通过龙头帽、龙角、蓝绿色龙须与尾巴等元素， 建立鲜明的东方识别度。

CHARACTER DESIGN

EMOTION SYSTEM

通过开心、惊讶、委屈、大哭、生气、眩晕、害羞、紧张等表情， 强化角色在社交传播场景中的亲和力。

APPLICATION SYSTEM

围绕角色形象与表情系统，延展出贴纸、钥匙扣、帆布袋、邮票、胶带等系列化文创产品。

DESIGN SUMMARY

该IP形象以东方文化为核心，通过角色设定、情绪系统与文创应用建立完整的视觉体系， 具备网页展示、社交传播和商业衍生的多重可能性。
